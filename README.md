# XContábil LP

🔗 [Acesse a landing page](https://sites.xweb.com.br/xcontabil-lp/)

O **XContábil LP** é uma landing page desenvolvida para captar leads de forma eficiente para escritórios de contabilidade. O layout é direto ao ponto, focado em conversão e adaptado para dispositivos móveis, garantindo excelente desempenho em campanhas de tráfego pago ou orgânico.

---

## 🎯 Objetivo

Aumentar a geração de leads qualificados para serviços contábeis através de uma página otimizada para:

- Conversão de visitantes em contatos/clientes
- Divulgação clara de serviços e diferenciais
- Carregamento rápido e experiência fluida

---

## 🧩 Recursos da Landing Page

- Seção de apresentação com chamada de ação (CTA)
- Destaques de serviços contábeis
- Formulário de contato integrado
- Design responsivo (mobile-first)
- Elementos animados e otimizados com Bootstrap 5

---

## 🛠️ Tecnologias Utilizadas

- HTML5 + CSS3
- Bootstrap 5
- JavaScript 
- PHP (para envio de formulário)
- Hospedagem via **XWeb Sites**
